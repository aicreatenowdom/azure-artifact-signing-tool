# Support

For Azure Artifact Signing Tool help, contact **AI Creations Now Software Development** at [info@aicreatenow.com](mailto:info@aicreatenow.com) or **1-866-315-4750**.

- [Official product page](https://aicreatenow.com/azuretool.html)
- [Company website](https://aicreatenow.com/)

Include your application version, Windows version, a description of the problem and the relevant error message. Remove passwords, authentication tokens, private file contents and other sensitive information before sharing diagnostics. Send sensitive account or licensing matters privately by email rather than posting them in a public issue.

Microsoft Azure account eligibility, identity verification, certificate profiles and service billing are managed through Microsoft.

## Before contacting support

- Identify the stage that failed: prerequisite preparation, Microsoft sign-in, resource selection, signing or verification.
- Say whether you selected one file or a batch. A PDF is expected only for single-file signing.
